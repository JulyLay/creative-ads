# Creative Ads - Claude Code Skill

Генератор рекламних креативів (статика, відео, анімація) з готовими AI-промтами для Midjourney / DALL-E / Nano Banana Pro / Higgsfield / Runway під усі рекламні платформи.

## Що робить

Перетворює аналіз цільової аудиторії на готові до запуску рекламні матеріали:

- **Статичні креативи** - банери з AI-промтами (Midjourney, DALL-E, NBP) + текстами + CTA
- **Відео-креативи** - покадрові сценарії з AI-промтами (Runway, Higgsfield) + субтитри
- **Вебінарні Reels/TikTok** - хуки, сценарії, текстові описи для просування вебінарів і live-шоу
- **Повні рекламні оголошення** - ready-to-upload в Ads Manager (primary text, headline, description, CTA)
- **Ретаргетинг-ланцюжки** - 3 етапи з окремими креативами на кожному
- **A/B варіації** - 3 варіації на кожен креатив (hook / image / CTA тести)

## Методології

Скіл об'єднує три фреймворки:

| Методологія | Що дає |
|---|---|
| **ДНК Клієнта** (Yuliia Laiko) | Глибинні сегменти, болі, внутрішній монолог, мова клієнта, тригери |

## Алгоритм роботи (8 кроків)

1. **Збір даних** - підтягує ДНК Клієнта (або запускає аналіз)
2. **Ступінь усвідомленості** - визначає холодний / теплий / гарячий трафік
3. **Креативна стратегія** - генерує кути для кожного зв'язку сегмент × біль × ступінь
4. **Статичні креативи** - AI-промти + тексти + композиція (3 A/B варіації)
5. **Відео / анімація** - покадрові сценарії + AI-промти для відеогенерації
6. **Повні оголошення** - ready-to-upload ad units для кожної платформи
7. **Ретаргетинг** - 3 етапи (бачив → клікнув → був на лендингу)
8. **Платформенна адаптація** - розміри, формати, особливості кожного майданчика

## Модуль: Вебінарні Reels (webinar-video-reels.md)

Спеціалізований регламент для створення рекламних Reels/TikTok для просування вебінарів і live-шоу:

- **12 типів хуків** - провокація, ідентифікація, цифровий шок, контраст та інші
- **4 категорії CTA** - лід-магніт, FOMO, цікавість, прямий виклик
- **Система FOMO** через незнання конкретних інструментів (не «використовуйте AI», а «ви не знаєте ЦІ 7 інструментів»)
- **Формат Димшакова** - відео з хуком-заголовком + структурований текстовий опис + CTA
- **Матриця генерації** - автоматичне створення за даними ДНК Клієнта (сегмент × біль × хук)

Побудований на основі Deep Research (13 джерел, 2025-2026): hook rate бенчмарки, FOMO-статистика, тренди коротких відео, фреймворки Hook-Story-Offer і PAS.
